# ADR-0004：顶部强化符文推荐弹窗

## Status

Accepted

## Context

采购阶段只有几秒钟可做选择。普通 Electron 窗口无法覆盖独占全屏，进程注入又会引入反作弊和维护风险。

## Decision

强化符文推荐弹窗使用无边框、透明、置顶且不抢焦点的顶部三卡窗口，只保证无边框窗口化全屏。产品不提供常驻右侧推荐列表。

## Consequences

- 左、中、右卡位顺序必须保持。
- 完整三卡结果才能首次显示；动画期间可短暂保留上一次完整结果。
- 连续 miss 后清空，离开斗魂对局立即清空。
- 玩家界面显示推荐度、选取率和有明确口径的数据，不把第三方未知口径简称为胜率。
