# 斗魂竞技场助手当前要求

本文件只记录稳定的产品要求。术语见 [CONTEXT.md](../CONTEXT.md)，技术取舍见 [ADR](./adr/README.md)，当前开放事项见 [STATUS.md](./STATUS.md)。早期 ARAM 规格已失效，不再作为实现依据。

## 产品范围

- 只支持斗魂竞技场。
- 通过只读 LCU 和屏幕分析获取状态，不自动执行强化符文选择。
- 核心体验是采购阶段的顶部强化符文推荐弹窗。
- 棱彩装备识别、英雄榜、符文榜和组合榜属于斗魂辅助能力。

## 行为要求

- 斗魂身份来自队列 ID `1700` 或 game mode `CHERRY`。
- 采购阶段由视觉 signal 判断；不能从 `InProgress` 直接推断。
- 三个候选保持左、中、右顺序；首次显示必须识别完整三卡。
- 动画期间允许短暂保留上一轮完整结果；连续 miss 或离开对局后清空。
- 当前英雄未知时不显示按英雄生成的推荐。
- 自动识别失败时，`F8` 触发一次手动刷新。

## 数据要求

- OP.GG 细节留在可替换 adapter 后，并使用应用数据目录中的 cache。
- UI 显示数据来源、获取时间和明确的失败状态。
- 平均名次、第一名率、选取率和推荐度遵循领域词表。
- 未验证口径的第三方字段不得作为本项目定义的胜率展示。

## 质量要求

- `zh-CN`、`en-US`、`zh-TW` 使用相同 i18n 键。
- renderer 通过 preload 和受信 IPC 访问 main process。
- 可写运行时文件统一经过 app paths 模块。
- 标准提交门槛为单元测试、lint、类型检查和构建全部通过。
